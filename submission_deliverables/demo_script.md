## Recording Tips for Maximum Judge Impact:
1. **Resolution & Audio:** Record in 1080p 60fps with clear, crisp microphone audio.
2. **Clean Window:** Use a dedicated browser profile with bookmarks bar hidden, tabs closed, and zoom set to 125%.
3. **Pacing:** Keep mouse movements smooth and intentional. Pause for 1 second when the Time Machine turns Red so the judges absorb the visual transition.
4. **Captions:** Hard-code burned-in captions or enable YouTube CC for maximum accessibility.
