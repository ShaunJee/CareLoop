# DSH Hacks V2: Hackathon Instructions & Submission Guidelines

> **Prize Pool:** $100k+ in prizes!  
> **Theme:** AI x Healthcare  
> **Organizers:** Hosted collaboratively by three youth-led organizations: **DeltaForge Hacks**, **NXT Horizon**, and **STEMise**  
> **Eligibility:** Global student competition open to students aged 13+ (Individual or Team)

---

## 1. Overview

**DSH Hacks V2** is a global student competition that brings together young innovators from around the world to transform bold ideas into technical products addressing the health challenges facing our world today.

The core mission of the competition is **building meaningful technical products in AI and healthcare that solve real-world problems**.

---

## 2. Competition Theme: AI x Healthcare

Participants will work individually or in teams to identify a real-world healthcare problem and design and develop a meaningful technical solution.

### Problem Scopes & Ideas
Projects may range across diverse clinical and healthcare domains, including:
- **Diagnostic Tools:** Tackling global disease burdens and early diagnosis.
- **Patient-Care Platforms:** Improving patient access, post-discharge transitions, and clinical outcomes.
- **AI-Powered Systems:** Reimagining how we detect, treat, and manage acute and chronic illness.
- **Health Systems & Simulations:** Optimizing hospital resource allocation, clinical communication, and triage.

### Technical Formats
Solutions can be developed in any format, including:
- Web applications or websites
- Mobile applications
- Simulations or modeling software
- Algorithmic pipelines or backend systems
- Hardware components (permitted as long as an active software/coding component is present)

### Role of Artificial Intelligence
Participants are encouraged to use AI to:
- Build meaningful, high-impact clinical and patient-facing solutions.
- Lower the technical barrier that poses challenges for beginners with ambitious project ideas.

---

## 3. Evaluation Criteria

Judging will be centered on five core pillars:
1. **Clinical Insight:** Clear understanding of a genuine, high-stakes medical or health-system problem.
2. **Creativity:** Originality and novelty in the proposed solution and architecture.
3. **Technical Depth:** Code quality, algorithmic rigor, intelligent integration of AI, and system reliability.
4. **Feasibility:** Practicality in real-world deployment, user accessibility, and safety considerations.
5. **Real-World Impact:** Potential to measurably improve healthcare outcomes, literacy, or workflow efficiency.

---

## 4. Submission Requirements

All participants must submit the following four deliverables:

| Deliverable | Format | Description |
| :--- | :--- | :--- |
| **1. Project Prototype** | Web app, mobile app, or interactive prototype | Must have user interaction capabilities. Hardware components are allowed if accompanied by a coding component. |
| **2. Demo Video** | Video recording / link | Video explaining the purpose of the project, showcasing key features, and demonstrating hands-on user interaction with the prototype. |
| **3. One-Page Project Description** | PDF format | A concise 1-page document describing the project purpose, target problem, architecture, and key features. |
| **4. Code Repository / PDF** | GitHub Repo or PDF document | A GitHub repository link or a PDF document showcasing all source code developed towards the creation of the project. |

---

## 5. CareLoop Project Checklist

Use this checklist to track project milestones against the hackathon requirements:

- [ ] **Working Prototype:** Fully functional interactive prototype with demo modes, user interaction, and responsive design.
- [ ] **Demo Video:** Structured walkthrough covering problem framing, user persona journey, core features, and live demo.
- [ ] **One-Page PDF:** Clean, professional summary covering problem statement, verified clinical citations, architecture diagram, and impact metrics.
- [ ] **Code Submission:** Public GitHub repository and generated Code PDF with clean commits and documentation.
